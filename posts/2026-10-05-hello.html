How this site works

Every HTML file in posts/ is published as-is, and the front page lists them newest first.

  1. Add posts/2026-10-05-my-report.html, or a folder posts/my-report/index.html if it has its own assets.
  2. Push to main. GitHub Actions rebuilds the listing and deploys.

The listing uses the page's <title>, <meta name="description"> and <meta name="author">. Add <meta name="unlisted"> to publish a page without listing it.
